<h1 align="center">🎲 Lottery Game 🎲</h1>

<p align="center">
A fun and interactive <b>lottery game</b> built using <b>React</b>. Users can generate lottery tickets anytime, and if the drawn number matches the winning condition, they win the lottery! <br><br>
🎯 Try your luck and
<a href="https://playlotterygame.netlify.app/" target="_blank"><b>Play Now</b></a>!
</p>

<hr>

<h2>✨ Features</h2>

<ul>
    <li>🎟️ Generate random lottery tickets instantly</li>
    <li>🏆 Winning condition validation</li>
    <li>⚡ Instant result feedback</li>
    <li>🔄 Unlimited retries and gameplay</li>
    <li>📱 Simple and responsive UI</li>
</ul>

<hr>

<h2>🛠️ Technologies Used</h2>

<ul>
    <li><b>React</b> for building the user interface</li>
    <li><b>JavaScript</b> for game logic and functionality</li>
    <li><b>CSS</b> for styling and layout</li>
    <li><b>Vite</b> for fast development and build tooling</li>
</ul>
